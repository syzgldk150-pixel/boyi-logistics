# 博益融辉原页验证扩展 0.3.1

作用于 https://boyi.homes/ocr 中的融辉真实原站 iframe，由博益后台提供安装包，尚未发布到扩展商店。0.3.1 从主站任意页面加载监听器，支持从首页局部切换到运单录入；适配仍只针对融辉 iframe，扩展后台仅接受博益主站顶层页面的准备消息。

## 使用

需要登录时，使用博益页签顶部的“在新窗口打开融辉”，完成后回到博益点“重新加载”。原页不能将博益整页跳转到外站。从原站菜单进入“运单录入”后，扩展自动收起融辉自身的顶部栏、侧栏和重复页签，让真实录单表单铺满内部标签。
上方“原站菜单”按钮可恢复完整原站，便于切换账号及使用其他功能；点击“仅显示录单”返回已打开的录单页。
切换仅调整布局，不重新加载、搬移或替换表单 iframe，不重新领号。扩展不会自动创建新的运单录入页。
登录页和单独在浏览器打开的融辉原站不改变布局。无账号隔离，同一浏览器的融辉标签共享账号。

## 登录适配

扩展在浏览器本机适配融辉 Cookie 的 SameSite/Secure 属性，并将已观察到的 HTTP 登录跳转改为 HTTPS。
登录信息只在浏览器内存中处理，不输出、不存文件、不上传。不改写业务请求正文或 CSP/X-Frame-Options。
停用/移除扩展后适配停止；已适配的 Cookie 属性保留到原站重设 Cookie 或用户正常退出、清理该站数据。

## 验证边界

Chrome 153：0.2 已验证内嵌登录、刷新保持、寄件人和收件人历史查询；0.3 增加录单展开与菜单恢复。
0.3.1 的局部导航启动、同一 frame 去重和来源边界有隔离回归；页面的快速加载、重载和顶层跳转阻断通过 Chromium 模拟原页验证，不代表真实扫码或业务保存已验收。
未验证：真实领号、保存、上传、打印、Edge/Firefox、全新浏览器配置首次安装。
当前页面用户已自行打开并取得运单号；布局更新保留该表单，没有刷新或提交它。

## 安装

从博益融辉页签的“下载内嵌扩展”取得 ZIP，解压到固定文件夹。打开 chrome://extensions（Edge 为 edge://extensions），开启开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的 extension 文件夹。Edge 兼容性仍待实测。
更新已有扩展时覆盖本目录，在扩展管理页点重新加载；业务页面下次正常打开时自动应用。
有未保存录单时不要刷新业务页面；请完成当前录单后再打开新页面。ECS 发布不会自动安装或升级每台电脑上的浏览器扩展。

文件：manifest.json、background.js、content.js、layout-host.js、layout-shell.js。
