# Console font assets

These files are versioned static assets so the Console does not rely on a third-party font CDN at runtime.

| File | Typeface | Upstream | License |
| --- | --- | --- | --- |
| `SourceHanSansCN-UI.woff2` | Source Han Sans CN Variable 2.005, Console UI subset | Generated from the bundled upstream file | SIL Open Font License 1.1 |
| `SourceHanSansCN-Common.woff2` | Source Han Sans CN Variable 2.005, GB2312 common-character complement | Generated from the bundled upstream file | SIL Open Font License 1.1 |
| `SourceHanSansCN-VF.ttf.woff2` | Source Han Sans CN Variable 2.005 | `adobe-fonts/source-han-sans`, `release/Variable/WOFF2/TTF/Subset/SourceHanSansCN-VF.ttf.woff2` | SIL Open Font License 1.1 |
| `InterVariable-Latin.woff2` | Inter Variable 4.1, Latin subset | Generated from the bundled upstream file | SIL Open Font License 1.1 |
| `InterVariable.woff2` | Inter Variable 4.1, retained upstream source | `rsms/inter`, official `v4.1` release | SIL Open Font License 1.1 |

The corresponding upstream license texts and redistribution terms apply. Do not replace these resources with a network-loaded font URL. Update this file with the source version and license whenever a binary changes.
