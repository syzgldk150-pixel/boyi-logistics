# Console 历史问题修复记录

> 本文件是 2026-03-11 审查的冻结快照，不是当前问题清单，也不表示此后没有新增问题。当前约束以 `console/AGENTS.md`、`console/CLAUDE.md`、代码和测试为准。

更新时间：2026-03-11

## 当时状态

- 本轮审查确认的 4 个缺陷已修复
- 截至该次审查结束，本文件没有记录新的阻塞问题

## 已修复项

1. 已修复文件服务目录穿越
   `/runtime/...` 与 `/static/...` 现在会校验解析后的目标路径必须仍位于允许目录内，越界请求返回 `404`。

2. 已修复重新处理失败时 HTTP 直接中断
   `reprocess_document()` 现在会捕获异常、把单据状态写成 `error`、记录 `error_message`，页面会显示失败提示。

3. 已修复人工确认绕过必填校验
   复核页点击“确认入库”时会重新跑字段校验，只有满足条件才会写成 `confirmed`，否则保持 `review_required`。

4. 已修复上传成功数统计不准确
   上传页现在会区分成功、失败、跳过三类数量，失败图片不会再算进“成功”。

## 回归结果

- 非法路径 `runtime/../../CLAUDE.md` 返回 `404`
- 非法单据 ID 不再导致连接断开，改为返回 `404`
- 缺失原图时，重新处理会把单据写成 `error`
- 空必填字段不能被直接“确认入库”
- 上传坏图时首页会显示 `成功 0 张，失败 1 张，跳过 0 张。`
