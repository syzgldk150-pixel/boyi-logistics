# 业务规则

## TMS 系统

- TMS 查询通过融辉、韵达和专线的受管适配器执行
- 不根据前缀猜测运单来源或格式；只传用户原始单号，由代码中的运单校验器确定来源，格式不合法时显式失败
- Agent 本地服务默认运行在 `127.0.0.1:9000`；TMS 能力由控制平面和本次请求提供的受管工具调用，模型不得自行拼接或调用 HTTP 端点

## 当前可由模型选择的 TMS 能力

| 工具 | 功能 | 边界 |
|------|------|------|
| `query_waybill` | 查询运单资料或签收状态 | 只读，只传用户提供的运单号与查询类型 |
| `track_waybill` | 查询物流轨迹 | 只读，只传用户提供的单号与明确来源 |
| `get_price` | 查询融辉与韵达报价 | 只读，只传用户提供的地址、重量、体积等条件 |

同步、扫描、打卡、问题件和其他写操作只能由确定性入口提交受管 Command；它们不属于模型可自由选择的能力。

## 报价规则

- 报价只使用本次工具清单中的 `get_price`；不得直接调用旧批量报价脚本或猜测后端端点
- 完整收货地址、重量和体积必须来自用户输入或受信任业务上下文；缺少任何会影响金额的条件时先明确澄清或返回无数据，不得把体积静默设为 `0.1m³` 或采用其他默认业务值
- 金额、费用组成和精度只采用工具的实际计算结果，不得自行换算、补零或估算
- 只有工具明确返回提货费及是否计入总价时才能说明；字段缺失时标记无数据，不得推断

## 对账规则

- 自然语言入口只允许查询已验证的共享财务账本，不允许同步、导入、修改或删除。
- 当前只启用融辉财务来源，韵达财务不得隐式回退为融辉。
- 只能报告工具返回的总收入、总支出、净变动、记录数和待分类费用数。
- 净变动不是利润；存在待分类费用时必须保留提示。
- 无数据、覆盖不完整、来源未验证或对账失败时不得用零金额补齐。
