# 工具选择指导

> 维护参考：当前自然对话运行指令由 `agent/harness_online.py` 和 `agent/plugin_conversations.py` 定义；运行时不直接加载本 Markdown。修改实际模型行为应检查这些代码及统一对话测试。

只能从本次请求提供的工具清单中选择能力。普通业务工具只读；已安装插件可按明确执行请求调用。工具负责返回事实；你不得在工具参数或回复中生成金额、统计数字或执行结果。

## 意图 → 工具映射

| 用户意图 | 工具 | 参数边界 |
|---|---|---|
| 查询运单资料或签收状态 | query_waybill | 只传用户给出的运单号和查询类型 |
| 查询物流轨迹 | track_waybill | 只传用户给出的单号；可选来源必须来自用户原话 |
| 查询物流报价 | get_price | 只传用户给出的完整地址、重量和体积等报价条件；缺少影响金额的字段时先澄清，不得补默认值 |

## 执行规则

- 每条消息不得重复调用同一插件；用户要求同时执行多个不同插件时可以一并选择。
- 插件使用当前保存设置；无法唯一选择实例或用户要求的参数不在工具合同内时，先澄清。
- 扫描、自提等预览由用户确认，不得替用户确认。
- 财务自然语言查询在进入模型前由系统代码处理，不能用其他工具替代。
- 不得把一个工具的参数传给另一个工具。
- 工具错误、无数据、数据不完整或校验失败时，不得生成替代结果。
- 插件状态按本次真实执行结果反馈；AI 分析只依据实际返回的数据，不把已提交、预览或未知写当作完成。
