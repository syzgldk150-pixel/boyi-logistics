# 财务对账模块

> 多账户、多支付渠道的物流收支对账系统。

---

## 模块职责

汇总并核对物流业务中各支付渠道（微信、支付宝、货拉拉、融辉系统）的资金流水，实现：
1. **逐笔资金追踪**：按运单维度关联各数据源的收支明细
2. **月度损益报表**：月度业务 + 专线独立损益 + 固定成本 → 综合净利润

## 当前状态：ETL 管道 v5.1 已完成

- 7个数据提取器 + 对账逻辑 + 报表生成，全部可运行
- 新增现金流水核对（月度收支 + 异常方向）
- 新增发票差异表（发票汇总 vs 融辉结算类型/月度）
- 修复货拉拉 19 位订单号在 cleaned / 报表中的精度丢失
- 新增关键金额口径自校验（源数据 → 清洗 → 汇总 → 对账）
- 修复销项发票汇总时空科目/空月份键被 `groupby` 丢弃的问题
- 运行命令：`cd finance_reconciliation && python -m etl.main`
- 输出：`output/reports/财务对账报表.xlsx`（12 sheets）
- 运行耗时：~36秒

### Agent 接入（Phase 2.5）

- Agent 工具包装器：`tools/finance_tool.py`
- 调用方式：通过 Agent subprocess 执行完整 ETL，再返回结构化 JSON
- 入参：`month`（可选，返回该月摘要） / `input_path`（可选，覆盖 `metadata/` 根目录）
- 出参：`report_path`、`summary`、`cash_summary`、`tracking_summary`、`log_excerpt`
- 路径覆盖：ETL 支持通过环境变量覆盖 `FINANCE_DATA_DIR` / `FINANCE_OUTPUT_DIR` / `FINANCE_TEMP_DIR`

## ETL 管道结构

```
finance_reconciliation/
├── etl/
│   ├── shared/
│   │   ├── config.py          # 路径常量、结算类型分类映射(78种→大类+子类+层级)
│   │   ├── decimal_utils.py   # Decimal 转换工具
│   │   └── validators.py      # 行数/总额/极值校验（已接入关键链路）
│   ├── extractors/
│   │   ├── ronghui.py         # 融辉系统流水 (23,787行)
│   │   ├── wechat.py          # 微信流水 (1,052→940行，去重112)
│   │   ├── alipay.py          # 支付宝流水 (1,172→1,040行，排除不计收支)
│   │   ├── huolala.py         # 货拉拉订单 (69行)
│   │   ├── yongsheng.py       # 勇胜运单 (月度2,615行 + 专线1,173行, 日期分隔行→月份)
│   │   ├── cash_flow.py       # 现金流量表 (参考数据源)
│   │   └── invoice.py         # 发票数据 (进项277行 + 销项68行, 汇总54行)
│   ├── reconcile.py           # 对账主逻辑 + 月度P&L + 专线独立损益 + 固定成本
│   ├── report.py              # Excel 报表生成 (12 sheets)
│   └── main.py                # 管道编排入口
├── output/
│   ├── cleaned/               # 8个清洗中间文件
│   └── reports/               # 财务对账报表.xlsx
└── temp/                      # 运行时临时文件（自动清理）
```

### 数据流

```
metadata/*.xlsx/csv → extractors (7个) → output/cleaned/ → reconcile.py（P&L + 现金核对 + 发票差异） → report.py → 财务对账报表.xlsx
```

### P&L 结构

```
一、营业收入 (客户运费 + 操作场补贴)
二、营业成本 (融辉运单级: 中转/干线/派送/操作/短驳等)
三、毛利
四、管理费用 (融辉系统级: 保险/短信/服务基金等)
五、货拉拉
六、固定成本 (装卸工3人 + 房租10530 + 客服1人)
七、月度净利润
八、专线损益 (收入=总金额, 成本=中转费, 独立于融辉)
九、综合净利润 = 七 + 八
十、融辉充值 (资金划转, 不影响利润)
十一、交叉验证 (勇胜vs融辉中转费对比)
十二、现金流水核对 (微信+支付宝月度收支/异常方向)
十三、发票差异表 (发票汇总 vs 融辉结算类型/月度)
```
