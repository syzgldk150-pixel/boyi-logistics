# 财务对账 - 数据结构分析

> 基于元数据目录的全量文件扫描结果。用户已确认核心业务逻辑。

---

## 0. 用户确认的业务决策

| 决策项 | 结论 |
|--------|------|
| 范围 | **先只做邓博严部分**，妈妈/爸的数据后续补充 |
| 银行流水 | 邓博严部分基本不涉及银行直接转账，已记录在现金流量表 |
| 应收帐款 | **保留文件但本阶段不处理**，所发货物在运单表里都有体现 |
| 维克零担 | 属于应收帐款部分，**本阶段不纳入** |
| 专线数据 | 三合/凯邦/一二/戴氏 **全部在对账范围内** |
| 现金流量表 | 仅作为数据来源使用，不需要自动生成后续月份 |
| 微信去重 | 按**交易单号**去重 |
| 付操作场补贴 | 是操作场30元/吨收入来源，但含其他费用（后续补充发票信息） |
| 重量单位 | 融辉结算重量 = **公斤** |
| 对账目标 | **两者都要**：月度损益报表 + 逐笔资金追踪 |
| 支付宝不计收支 | **不纳入对账**，仅审核收入/支出流水 |
| 融辉聚合维度 | **按运单维度**汇总 |
