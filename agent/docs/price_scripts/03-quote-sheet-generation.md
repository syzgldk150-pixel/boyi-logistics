# 模块三：报价表生成

> 读取 TMS 原始报价数据，生成明细单价中间表，再结合物流托运单历史频次生成最终客户报价表。

---

## 模块职责

对模块二产出的原始报价数据进行单价计算和聚合，最终输出面向客户的物流频次报价表。

## 遵循规范

严格遵循 `财务与数据相关任务基准逻辑.md`：

- 所有金额使用 `Decimal` 精度
- 向上进位（`ROUND_CEILING`）：0.241 → 0.25
- 明细单价 / 物流频次报价 / 自提部补价共用 `shared/price_utils.py`
- `shared/price_utils.DEFAULT_MARGIN = 0.15`；客户报价表、`liveTMS_*` 审计列、以及回写后的客户报价表统一使用该利润口径
- 自验证校验（区县数一致、报价总数一致、反算误差检查）

## 生成明细单价表.py 核心逻辑

### 数据清洗

| 步骤 | 说明 |
|------|------|
| 排除「地址解析失败」 | 匹配网点名称含"失败" |
| 排除「服务大厅」 | 匹配网点名称含"服务大厅"（到不了的地方） |
| 排除 费用/区间为空 | 无报价数据 |
| 排除「0-100kg」 | 不纳入分析 |

### 单价公式

```
单价(元/kg) = 总费用(元) ÷ 最高单价对应重量(kg)
```

### 取最低单价逻辑

按 (省份, 城市, 区/县, 派送方式, 重量区间) 分组，对所有产品类型（融速达/融安达/融惠达/精准零担）取 `min(单价)`。

### 输出格式

派送、自提各一个 Sheet，结构相同：

| 省份 | 城市 | 区/县 | 101-150kg | 151-300kg | 301-350kg | 351-800kg | 801-1500kg | 1501-3000kg | 3001+kg |

## 生成物流频次报价表.py 核心逻辑

### 策略

1. 从勇胜物流托运单提取历史目的地，统计各省高频目的地（仅市/区，TOP10）
2. 匹配全国明细单价表（自提），找到对应区域的单价
3. 匹配规则：只保留“市→区”层级。区级目的地按区精确匹配；城市目的地仅在下辖区中取最低单价；县/旗/镇/乡/村等区以下目的地直接排除，不参与统计
4. 无法在主数据源匹配时，回退到原始报价数据（含服务大厅）；2026-03-14 版当前仍有 1 行回退源
5. 7段合并为3段（去掉3001+kg），取子段max
6. +0.15元/kg利润，Decimal向上进位
7. 匹配区域列仅显示 1 个实际取值的最低价区；若多个区并列最低，稳定选择其中一个区显示，便于溯源

### 当前成品口径

- `输出结果/客户报价表.xlsx` 中的 3 个价格列不是裸成本单价，而是已经加计 `+0.15 元/kg` 后的客户报价
- `审计客户报价表_live_tms.py` 导出的 `liveTMS_101-300kg / 301-800kg / 801-3000kg` 也是同一利润口径
- `回写客户报价表_live_tms.py` 只是用同口径的 `liveTMS_*` 覆盖现表，不会把利润层回退成成本价

### 配置参数

| 参数 | 值 | 说明 |
|------|------|------|
| `MERGE_MAP` | 7→3段 | 101-300kg / 301-800kg / 801-3000kg |
| 利润 | +0.15 元/kg | 成本价上加利润，Decimal ROUND_CEILING |

### 输出格式

1 个 Sheet「自提报价(按物流频次)」：

| 省份 | 目的地 | 匹配区域 | 101-300kg | 301-800kg | 801-3000kg |

## 补充自提部报价.py 核心逻辑

### 策略

1. 从 `分拨信息地址最新版7.1.xlsx` 读取分拨名称和仓库地址
2. 通过 `PROVINCE_DEPOT_MAP` 映射 27 省→31 个现役自提部（跳过青海/西藏/新疆/海南；已移除撤销网点浦东/佛山）
3. 对每个 "{分拨名称}自提部" 调用 TMS API（复用 `batch_run_by_site._login/_fetch_one_by_site`）
4. 价格处理：自提筛选→排除 0-100kg→单价=总费用/最高单价对应重量→每重量段取产品最低→7→3 合并（取子段 max）→+0.15 利润→Decimal ROUND_CEILING
5. 插入到客户报价表.xlsx 每省第一行之前，检测已有自提部行防重复

### 省份映射特殊情况

| 省份 | 分拨名称 | 说明 |
|------|---------|------|
| 北京 | 北京通州, 北京房山 | 2 行（TMS 无"北京自提部"） |
| 上海 | 浦西 | 浦东自提部已撤销，不再纳入任务 |
| 广东 | 虎门, 中山, 潮汕, 深圳 | 佛山自提部已撤销，不再纳入任务 |
