# TMS 价格结构分析（逐公斤扫描）

> 通过对两个不同地址（杭州西湖区、哈尔滨双城区）进行 1-3000kg 逐公斤价格扫描，验证 TMS 价格结构规律。
> 分析逻辑：四产品（融安达/融速达/精准零担/融惠达）× 两派送方式（自提/派送），每个重量点取每公斤单价最低的。

---

## 核心结论：价格结构全国统一

经两个地址验证，TMS 的**价格区间划分、产品切换逻辑、最高单价对应重量**完全一致，不同地址仅费率系数不同。

- 全程最优均为 **自提**，派送从未胜出
- 产品切换点统一在 **801kg**：融速达(自提) → 精准零担(自提)
- 融惠达（>3000kg 才适用）在本扫描范围内未出现

---

## 单价逆增分析

在公斤数递增过程中，只有 **4 个点**出现最低单价微幅上升：

| 位置 | 涨幅(元/kg) | 原因 |
|------|-----------|------|
| 299→300kg | +0.0066 | 区间边界跳价（边际从0.65跳到2.64） |
| 799→800kg | +0.0037 | 区间边界跳价（边际从0.65跳到3.64） |
| 1499→1500kg | +0.0007 | 区间边界微调 |
| 2999→3000kg | +0.0003 | 区间边界微调 |

前两个涨幅不到 1%，后两个可忽略。整体趋势为**单价随重量递增而递减**。
