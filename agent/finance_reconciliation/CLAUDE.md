# 财务对账模块

> 详细文档：`docs/finance_reconciliation/`

## 状态：ETL 管道 v5.1（现金流水核对 + 发票差异表 + 货拉拉订单号保真 + 金额口径校验）

## 运行命令

```bash
cd "finance_reconciliation"
python -m etl.main          # 完整管道: 提取→对账→报表
python -m etl.extractors.ronghui   # 单独运行融辉提取器
python -m etl.extractors.wechat    # 单独运行微信提取器
python -m etl.extractors.alipay    # 单独运行支付宝提取器
python -m etl.extractors.huolala   # 单独运行货拉拉提取器
python -m etl.extractors.yongsheng # 单独运行勇胜提取器
python -m etl.extractors.cash_flow # 单独运行现金流量表提取器
python -m etl.extractors.invoice   # 单独运行发票提取器
python -m etl.reconcile            # 单独运行对账（需先运行提取器）
```

## 自校验机制

- 提取阶段已接入金额口径校验：融辉删除过滤、微信去重、支付宝过滤、货拉拉金额转换、发票汇总、勇胜客户运费反算
- 对账阶段已接入金额口径校验：理赔正值过滤、现金流水月度汇总
- 现金流水异常方向单独输出到 `现金流水异常` sheet，避免异常值混入正常收支口径

## 融辉符号约定（已确认）

- **正值 = 钱流入我们账户**（平台付给我们，如付操作场补贴）
- **负值 = 钱流出我们账户**（平台向我们收取，如收中转费）
- "收"前缀 = 平台向我们收取 → 大部分为负值 → 我们的成本
- "付"前缀 = 平台付给我们 → 大部分为正值 → 我们的收入

## 核心业务决策

- 范围：先只做邓博严部分
- 聚合维度：按**运单维度**
- 目标：月度损益报表 + 逐笔资金追踪
- 重量单位：公斤
- 付操作场补贴 = 操作场收入（含其他费用，待发票细分）
- 专线数据（三合/凯邦/一二/戴氏）：**独立于融辉，P&L中单独核算**
  - 收入=总金额，成本=中转费（来自勇胜运单表），送货费=总金额-基本运费
  - 月份从日期分隔行提取（非 sheet 名推断），三合8 含 07+08 两月
- 应收帐款表：保留文件，本阶段不处理
