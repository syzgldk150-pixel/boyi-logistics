# 身份、统一对话与 V2 插件验证记录

本次变更将普通后台账号与飞书账号的权限统一为可配置身份；两个聊天入口共用实际会话服务和模型工具链。V2 包承载现有业务算法，宿主补齐已审核的基础接口、实际结果验证及迁移归属。

本文记录源码和隔离验证。发布结果另行记录；不能把本地包版本、测试成功或工作区基线 SHA 当作 ECS 已升级的证据。

## 已实现的行为

- 超级管理员创建身份并勾选功能权限；普通后台账号分配身份，飞书绑定可继承身份或后台账号。后台集中显示有效、失效和已解绑的飞书绑定，可以改备注、变更继承目标和解绑。
- 权限实时作用于页面、HTTP 接口、业务查询、财务、插件调用和 AI 工具；不能仅通过隐藏菜单实现权限限制。旧账号和绑定通过新增迁移保留原归属。
- 后台 AI 与飞书自然语言共用同一会话服务、当前模型与业务查询。固定脚本关键词直接执行；账号与渠道身份分别核验，群聊上下文按发送者隔离。
- 现有业务 V2 ZIP 通过真实隔离进程调用宿主接口。扫描、统计、自提、分批以及财务、客服、清单、寄件、签收、每日应签使用实际算法，外部接口仅在隔离测试边界替换。
- 迁移验证阶段不会提前接管定时、飞书或 Webhook；正式切换保留启停及配置。刚被接受但尚未创建执行租约的调用也会阻止切换，已取消的历史调用不会形成积压。

维护归属与局部测试/打包命令见 [V2 维护入口](../agent/service_v2_plugins/README.md)，运行边界见 [插件平台](plugin-platform-v2.md)。

1. ECS 仍运行本轮改造前版本。V1 源实例尚未逐个完成线上 V2 切换，不能提前删除 V1 启动、签名发行及运行依赖。

3. 用户全局规则禁止访问凭据文件。本轮未读取签名私钥；需通过用户授权的受保护签名流程或取得已签名发行包，才能继续现有发布流程。
4. 迁移 READY 要求目标当前代的实际成功调用。没有只读预览的插件需要单独明确的生产业务验证授权，不能用假结果或隔离记录冒充线上结果。

## 复现与回滚

所有测试使用 Python 3.10、项目锁定依赖以及 `PYTHON_DOTENV_DISABLED=1`。普通测试入口为 `python -m pytest -q tests`、`python -m pytest -q agent/tests` 和 `python -m pytest -q console/tests`，Agent/根目录设置 `PYTHONPATH=agent:.`，Console 设置 `PYTHONPATH=.`。

数据库专项仅使用隔离 MySQL：设置 `RUN_MYSQL_INTEGRATION=1`、回环 `AGENT_DB_HOST`、隔离端口和以 `_test` 结尾的库名。涉及实际浏览器的测试还须把 `V32_CHROMIUM_EXECUTABLE` 设置为已安装 Chromium 的绝对路径，不可用时不得跳过后称通过。

局部维护入口：`python -m scripts.plugin_maintenance test <插件ID>`；测试后打包：`python -m scripts.plugin_maintenance package <插件ID> --output <新ZIP路径> --report <新JSON路径>`。V2 版本在 Manifest 中修改。

核心发布采用 [ECS 标准流程](../agent/deploy/publish_to_ecs.md) 的 shared 路径。迁移 047 改变共享权限结构；服务重新开放前的失败使用当次精确源码、依赖和数据库备份恢复。开放后已有新业务写入时，不得通过整库回滚抹掉新数据，应保留权限结构向前修复。

V2 插件回退使用实例已安装过的原 ZIP，并保持账号与资源配置。V1→V2 入口切换完成之前，可通过对应迁移记录回退入口；完成线上验收之前保留原版本恢复材料。
